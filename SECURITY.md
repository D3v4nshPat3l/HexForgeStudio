# Security Policy

## Supported version

The latest release on the `main` branch receives security fixes.

## Reporting a vulnerability

Please use the repository's **Security** tab and open a private security advisory. Do not publish exploit details or sensitive sample files in a public issue.

Include:

- A clear description of the vulnerability
- Reproduction steps
- Affected browser and operating system
- Security impact
- A minimal safe proof of concept

## Processing model

HexForge Studio Pro is designed to process files locally in the browser. Changes that introduce network transmission, telemetry, remote parsing, or third-party file uploads must be explicitly documented and reviewed.
