# Format compatibility

All files are compatible with raw hexadecimal viewing, searching, overwriting, hashing, entropy analysis, string extraction, comparison, source export, and PDF reporting.

Specialized detection or structural detail is implemented for:

TIFF (.tif, .tiff), Canon CR2 (.cr2), extension-assisted NEF (.nef), ARW (.arw), DNG (.dng), ORF (.orf), RW2 (.rw2), RAF (.raf), CR3 (.cr3), ICO (.ico), PSD (.psd), SVG (.svg), JPEG 2000 (.jp2, .j2k, .j2c), OpenEXR (.exr), PNG, JPEG, GIF, BMP, TAR (.tar), ZIP and ZIP-derived containers, GZIP, BZIP2 (.bz2), XZ (.xz), 7-Zip, RAR, CAB (.cab), ISO 9660 (.iso), DMG (.dmg), VHD (.vhd), VHDX (.vhdx), QCOW2 (.qcow2), WAV (.wav), FLAC (.flac), OGG (.ogg), AAC ADIF/ADTS (.aac), AIFF/AIFC (.aiff, .aif, .aifc), MIDI (.mid, .midi), AVI (.avi), MKV (.mkv), WebM (.webm), MPEG program and elementary streams (.mpeg, .mpg), FLV (.flv), WMV/ASF (.wmv, .asf, .wma), MP3 with or without ID3, ELF, Mach-O, PE/COFF, Java Class (.class), Android DEX (.dex), UEFI firmware volumes, EFI PE images (.efi), U-Boot images, Linux x86 bzImage, Intel HEX, Motorola S-record, EPUB (.epub), CHM (.chm), DjVu (.djvu), PDF, PostScript/EPS (.ps, .eps), XML (.xml), HTML (.html, .htm), JSON (.json), CSV (.csv), plain text (.txt), ODS (.ods), and ODP (.odp).

Browser-native visual preview depends on the browser decoder. PNG, JPEG, GIF, WebP, SVG, BMP, ICO, and AVIF are commonly previewable. Formats such as PSD, EXR, TIFF, RAW, JPEG 2000, disk images, archives, and executable formats remain fully hex-editable but require additional decoders for rendered preview.
